# Wissensdatenbank

Fachwissen, das unabhängig von dieser Anwendung gilt: die fachlichen Regeln, die Begriffe, die
Fremdsysteme und die Formate, mit denen die Anwendung leben muss.

Bewusst getrennt von der technischen Dokumentation — das hier überdauert jede einzelne
Implementierung, und man sollte es lesen können, ohne die Codebasis zu kennen.
