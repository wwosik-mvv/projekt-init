# Baza wiedzy

Wiedza dziedzinowa prawdziwa niezależnie od tej aplikacji: reguły biznesowe, terminologia,
systemy zewnętrzne i formaty, z którymi aplikacja musi żyć.

Celowo trzymana osobno od dokumentacji technicznej — to przetrwa każdą pojedynczą implementację
i powinno dać się to przeczytać bez znajomości kodu.
