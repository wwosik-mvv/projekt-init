# Technische Dokumentation

Architekturdokumentation nach **arc42**: eine Datei je Abschnitt, nummeriert in der Reihenfolge
von arc42. Sie beschreibt das System, wie es gebaut ist, nicht wie es einmal geplant war.

Abschnitte, zu denen es nichts zu sagen gibt, bleiben kurz und sagen genau das — eine leere
Überschrift ist besser als erfundener Inhalt.
