# Dokumentacja techniczna

Dokumentacja architektury według **arc42**: jeden plik na sekcję, ponumerowane w kolejności
arc42. Opisuje system taki, jaki jest zbudowany, a nie taki, jaki kiedyś planowano.

Sekcje, w których nie ma nic do powiedzenia, zostają krótkie i mówią wprost, że nie ma — pusty
nagłówek jest lepszy niż zmyślona treść.
